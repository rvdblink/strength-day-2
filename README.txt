STRENGTH DAY 2 – iPHONE WEB APP
================================

Option A: Try the single-file HTML
- Use Strength-Day-2.html (provided separately), save it in Files on the iPhone and open it.
- The page works without internet, but the iOS Files preview / locally opened pages may block or clear website storage. Do not rely on it without trying a close-and-reopen test.
- Export backups regularly if using a local file.

Option B: Install as a Safari Home Screen web app (recommended for more reliable persistence)
- Upload all the files in this ZIP to an HTTPS static web host (e.g. GitHub Pages) without changing filenames.
- Visit your HTTPS URL in Safari on your iPhone.
- Choose Share > Add to Home Screen > Add.
- Open the new Strength Day 2 icon. It saves workouts to the browser's local storage, scoped to this website/app, and the service worker caches the app for offline use after the first visit.
- Use the Export backup feature occasionally. Browser storage can be cleared by device cleanup, site data deletion or changing browsers.

WHAT IS SAVED
- Every session's date, week, 27 checkboxes, weight for each set, bridge reps and session notes.
- A new session carries forward the previous logged weights, without inheriting the checkboxes.
- Backups are JSON files you can keep in iCloud Drive and restore via the Restore backup button.

PRIVACY
- No accounts, trackers, servers or network APIs. All workout data remains on the device unless you export it.
